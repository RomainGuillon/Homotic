## Conseils

- **Cadrer sur la zone utile** plutôt que sur l'écran entier : une capture
  du seul bloc concerné vieillit mieux et reste lisible sur téléphone.
- **Largeur ~1400 px** suffit ; au-delà le fichier grossit sans gain.
- Masquer les valeurs sensibles avant de publier : clés d'API, identifiants,
  adresse e-mail dans le paramétrage Enphase.
- Pour ajouter une capture non prévue, l'insérer dans le document avec
  `![Description](images/nom-du-fichier.png)` et compléter ce tableau.
